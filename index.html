Citations & References

Geo-KTF maps geospatial concepts to representative tools. Tool descriptions and capabilities are informed by the official documentation and project materials of the software ecosystems below. Please cite the original projects when using these tools in research or production work.

  • QGIS — QGIS.org. QGIS Geographic Information System. Open Source Geospatial Foundation. Documentation: https://docs.qgis.org/
  • GDAL/OGR — GDAL/OGR contributors. GDAL — Geospatial Data Abstraction Library. OSGeo. Documentation: https://gdal.org/
  • PROJ — PROJ contributors. PROJ coordinate transformation software library. OSGeo. Documentation: https://proj.org/
  • PostGIS — PostGIS Project Steering Committee. PostGIS — Spatial and Geographic Objects for PostgreSQL. OSGeo. Documentation: https://postgis.net/documentation/
  • pgRouting — pgRouting Community. pgRouting — Routing on PostgreSQL/PostGIS. Documentation: https://docs.pgrouting.org/
  • GeoPandas — GeoPandas developers. GeoPandas. Documentation: https://geopandas.org/
  • Shapely — Shapely developers. Shapely: manipulation and analysis of geometric objects. Documentation: https://shapely.readthedocs.io/
  • Rasterio — Mapbox / Rasterio contributors. Rasterio: access to geospatial raster data. Documentation: https://rasterio.readthedocs.io/
  • PDAL — PDAL contributors. Point Data Abstraction Library. Documentation: https://pdal.io/
  • PySAL — Rey, S. J., et al. Python Spatial Analysis Library (PySAL). Documentation: https://pysal.org/
  • Orfeo ToolBox (OTB) — CNES / OTB community. Orfeo ToolBox. Documentation: https://www.orfeo-toolbox.org/
  • openrouteservice — HeiGIT / openrouteservice. openrouteservice API. Documentation: https://openrouteservice.org/
  • OSRM — Project OSRM. Open Source Routing Machine. Documentation: https://project-osrm.org/
  • Valhalla — Valhalla contributors. Valhalla Open Source Routing Engine. Documentation: https://valhalla.github.io/valhalla/
  • MapLibre GL JS — MapLibre contributors. MapLibre GL JS. Documentation: https://maplibre.org/
  • Leaflet — Agafonkin, V., et al. Leaflet — an open-source JavaScript library for interactive maps. Documentation: https://leafletjs.com/
  • OpenLayers — OpenLayers contributors / OSGeo. OpenLayers. Documentation: https://openlayers.org/
  • GeoServer — GeoServer contributors / OSGeo. GeoServer. Documentation: https://docs.geoserver.org/
  • Apache Sedona — Apache Sedona. Sedona: a cluster computing system for processing large-scale spatial data. Documentation: https://sedona.apache.org/
  • DuckDB Spatial — DuckDB Labs / DuckDB Spatial extension authors. DuckDB Spatial. Documentation: https://duckdb.org/docs/extensions/spatial.html
  • scikit-learn — Pedregosa, F., et al. Scikit-learn: Machine Learning in Python. Documentation: https://scikit-learn.org/
  • OpenStreetMap — OpenStreetMap contributors. OpenStreetMap. https://www.openstreetmap.org/copyright
  • UCGIS Body of Knowledge — University Consortium for Geographic Information Science. GIS&T Body of Knowledge (visual inspiration for the circle-packing knowledge explorer). https://gistbok.ucgis.org/
